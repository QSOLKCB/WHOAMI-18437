## Actual runtime

The actual executable is intentionally boring:

```text
npm run whoami
  → Node.js
  → deterministic list of twelve wrapper names
  → TRENT
```

No network access or third-party packages are required.

## Cursed runtime

The files under `cursed/` preserve the architectural escalation as software-art exhibits. They are intentionally cross-era, internally ridiculous, and not intended to form one production-deployable application.

The recurring invariants are:

- `identity = TRENT`
- `determinism = MANDATORY`
- `restMode = never`
- `failure = unrepresentable`
- `necessity = false`

## Claim boundary

The transcript contains numeric values such as `18,437 orchestration tokens` and `847 spans`. This repository preserves those values as transcript-defined satire. It does not elevate them into measured benchmark results.

The phrase **wrapper-induced semantic displacement** is used here as a descriptive label for the observed conversational pattern, not as a universal scientific law.
